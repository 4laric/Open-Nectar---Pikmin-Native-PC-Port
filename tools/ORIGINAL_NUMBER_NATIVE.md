## Producer integration contract

The actual scene Services owner implements `PcOriginalNumberAuthority` against
the same `Native.contents()` journal. `pending` is valid only during the real
fresh `beginContents`/`endContents` scope. It reads the actual incomplete journal
row with attempted=true and born=false. It authenticates the complete source
identity and independently proves the real root source type (Egg37 or captured
Qurione16). It never creates a replacement journal or guessed source identity.

After that scope ends, `completed` reads the same retained journal and verifies
the selected scene catalog and successful matching child. `consumeAccepted`
returns false without changing the journal, or true only after synchronously
publishing the exact child's consumed state through actual EggContents.consume.
An adapter and its Native journal/catalog/Services must outlive all borrowed
numeric bodies, including after the parent actor dies. Call the read-only
authority-idle and teardown guards before owner disposal. Destroying a borrowed
authority aborts; it cannot silently leave dangling bindings.

The source Onyon bridge preflights the full typed numeric cause before journal
consumption, commits lineage after verified consumption, and increments the
native pending queue last. Duplicate accepted deliveries grant zero. A retired
source numeric config without a current receipt refuses ordinary yield fallback.
Live numeric bodies hold course teardown and Party SAVE capture until a full
physical graph codec and cold restoration exist.
